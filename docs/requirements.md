# Requirements

## Functional Requirements

### User

* Register, log in and log out
* View and edit profile information
* Set a preferred dietary type
* Browse recipes from all users
* View recipe details including ingredients, instructions, cooking time and dietary type
* Search recipes
* Filter recipes by dietary type
* Create, edit and delete own recipes
* Upload recipe images, with a default image if none is provided
* Add recipes to a weekly meal planner by date and meal time
* View, edit and remove planned meals

### Admin

* Access protected admin functionality
* Create, view, edit and delete all recipes
* View, create and edit users
* Block and unblock users
* View all users' meal plans

## Planned Additional Features

* Adjust ingredient quantities based on servings
* Generate a shopping list from the weekly meal plan
* Combine matching ingredient quantities in the shopping list

## Possible Future Features

* Saved/bookmarked recipes
* View previous weeks in the meal planner
* Recipe ratings
* Other nice-to-have features if time allows

## Product Principles

* Focus on the enjoyment of cooking, eating and discovering food
* Deliberately no calorie or nutrition tracking
* No weight-loss or diet-focused functionality

## Non-Functional Requirements

* Responsive design for mobile and desktop
* Client-side and server-side form validation
* Secure password hashing and authentication
* Role-based authorization and ownership checks
* Maintainable project structure following Symfony conventions
